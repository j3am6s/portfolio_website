# MANON VU HUU — corrected font edition

Open `index.html` to view the site, or publish the *contents* of this folder to GitHub Pages. **Nothing needs to be copied in from another ZIP:** the original Uttara font files used by the reference title are now included in `fonts/title.woff2` and `fonts/title.woff`.

## Updates
- Actual original high-contrast, narrow serif (Uttara, internally named `title`) on **every text element**, without Times New Roman fallback.
- Home title set on two centered lines: **MANON** / **VU HUU**.
- Existing green-and-white animated cursor, vertical scrolling, four sections, off-white active tab, small content typography and footer removal retained.
- Original PDF papers kept under `pdf/`.

## Customize
- Add your portrait as `images/portrait.jpg`.
- Edit the About Me placeholder in `index.html`.
- Edit the email, LinkedIn and GitHub placeholders in Contact.

No build steps or online font services are required. Keep the `fonts/` and `pdf/` directories alongside `index.html` when uploading.
